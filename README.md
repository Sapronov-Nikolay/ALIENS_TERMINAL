# 🖥️ ALIENS - TERMINAL (Симулятор терминала по фильмам Aliens)

Этот проект - интерактивная стилизация компьютерных терминалов из вселенной фильмов "Чужой" (Alien).
Вы пишете текст в консоль среды разработки или терминала, на котором запущен проект.
После нажатия на Enter, в браузере посимвольно печатается текст на чорном экране с эффектом старого CRT-монитора,
сопровождаясь механическими щелчками и фоновым гулом, в зависимости от выбранного стиля звука.

Проект создан в эксперементальных учебных целях для практики связки **Python (WebSocket-сервер)** и **Frontend (HTML, CSS, JavaScript)**

## ✨ Возможности

- **Связь в реальном времени:** Python и браузер общается через WebSocket.
- **Эффект печатной машинки:** Текст появляется посимвольно с настраиваемой скоростью.
- **Генерация звука (Web Audio API):** Звуки щелчков и гул генерируются прямо в браузере кодом (без использования mp3/wav файлов).
- **Библиотека звуковых пресетов:** Вы можете переключать звуковые темы (Ностромо, Хадли, Фиорина и др.) прямо на странице через выпадающее меню.
- **CRT-эффект:** Мерцание экрана, текстура разветки и фосфорицирующее свечение текста.

## 🛠️ Установка и запуск

Для работы потребуется `Python 3.8+` и установленная библиотека `WebSocket`.

* Активируйте виртуальное окружение (если оно есть): `.venv\Scripts\Activate`
* Установите зависимость: `pip install websockets`
* Запустите сервер: перейти в папку server с файлом server.py `cd server`, затем ввести команду запуска `python server.py`
